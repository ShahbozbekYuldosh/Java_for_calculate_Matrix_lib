# JavaMatrixLibrary / JavaMatrixKutubxonasi

**English:**  
**JavaMatrixLibrary** is a lightweight and versatile Java library for matrix operations. Designed with object-oriented principles, this library provides a clean and intuitive API for performing a wide range of matrix manipulations, making it suitable for learning, research, or integrating into larger Java projects.

**O‘zbekcha:**  
**JavaMatrixKutubxonasi** - bu matritsalar bilan ishlash uchun mo‘ljallangan yengil va sodda Java uchun qilgan kutubxona loyiham. OOP tamoyillarga asoslangan, sodda va tushunarli API orqali turli matritsa operatsiyalarini bajarish imkonini beradi. Ushbu kutubxona o‘rganish, tadqiqot yoki katta Java loyihalariga integratsiya qilish uchun mos keladi degan umiddaman.

---

## Features / Xususiyatlar

**English:**
- Matrix Creation: Initialize matrices of any size
- Basic Operations: Addition, subtraction, multiplication
- Advanced Operations: Transpose, determinant, inverse
- Element Access & Modification: Get and set matrix elements
- Object-Oriented Design: Fully encapsulated classes with constructors, getters, and setters
- Extensible API: Easily add new operations and functionalities

**O‘zbekcha:**
- Matritsa yaratish: istalgan o‘lchamdagi matritsalarni yaratish
- Asosiy operatsiyalar: qo‘shish, ayirish, ko‘paytirish
- Murakkab operatsiyalar: transpose, determinant, inverse
- Elementlarga kirish va o‘zgartirish: matritsa elementlarini olish va o‘rnatish
- Ob’ektga yo‘naltirilgan dizayn: konstruktorlar, getter va setterlar bilan to‘liq kapsulyatsiya
- Kengaytiriladigan API: yangi operatsiyalar va funksiyalarni oson qo‘shish
